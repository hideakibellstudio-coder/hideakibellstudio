How publishing works

O site é estático (GitHub Pages), então o conteúdo publicado são os arquivos /content/*.json do repositório. Você tem 3 caminhos, do mais seguro ao mais prático:
1. Salvar → guarda só no seu navegador (pré-visualização, nada público).
2. Exportar JSON → baixa os 3 arquivos para você commitar manualmente.
3. Publicar no GitHub → faz o commit pela API do GitHub usando um token fine-grained (somente este repositório, permissão Contents: Read and write).
